# BOTWAVE

Independent games, original worlds, and development updates from **botwave1904**.

## Games
- **[Nadie Mira Arriba](https://botwave1904.github.io/nadie-mira-arriba/)** — four acts, seven weapons, original lotee art. Play in a WebGL 2 browser or download the Android debug APK from the game page. Keyboard or compatible gamepad required; no touch controls in this build.
- **lotee — Lotería del Horror Moderno 2.0.** Free, offline-capable browser lotería. [Current play link on the studio website](https://botwave1904.github.io/#games).

**[Studio website](https://botwave1904.github.io/)** · [GitHub projects](https://github.com/botwave1904?tab=repositories)

Android downloads are debug/sideload builds, not Play Store releases. Third-party credits and licences are included in the game.
